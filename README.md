# 💸 SplitWise Clone - Frontend

A modern and responsive expense sharing web application inspired by **SplitWise**, built using **React** and **Vite**. This application helps users manage shared expenses with friends, track balances, chat in real-time, and settle payments easily.

🌐 **Live Demo**

https://parthivjain.github.io/frontend-splitwise/

---

# ✨ Features

## 🔐 Authentication

- User Signup
- User Login
- Forgot Password (OTP Verification)
- Reset Password

---

## 👤 User Profile

- Upload Profile Picture
- Persistent User Session

---

## 👥 Friend Management

- Add Friend
- Delete Friend
- Search Friends
- View Friend Details

---

## 💰 Expense Management

- Add Transactions
- Money Given
- Money Taken
- Transaction Categories
- Balance Calculation

---

## 🤝 Settlement

- Smart Settlement
- Update Balance Instantly
- Track Pending Amount

## 💬 Real-Time Chat

- Live Chat

- Chat History

## 🔔 Notifications

- Chat Notifications
- Settlement Notifications

## 📜 History
